NASA Solar Flare Predictor

A machine learning application that predicts solar flare activity using historical solar observation data.

Features

- Data preprocessing and feature engineering
- Machine learning model training and evaluation
- Solar flare prediction interface using Gradio
- Interactive web application

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Gradio
- Matplotlib

How to Run

bash
pip install -r requirements.txt
python app.py

Project Overview

This project was developed during an ML workshop and demonstrates the end-to-end machine learning workflow for predicting solar flare events from solar activity data.
